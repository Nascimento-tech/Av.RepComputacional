Grafo com lista de adjacência, usando o [Av.RepComputacional](https://github.com/Nascimento-tech/Av.RepComputacional) como base.

Para executar:

```bash
python cod_final.py
```

Cadastre os vértices e as arestas pelo menu. A opção 4 faz a busca em largura a partir de uma origem. A opção 5 encontra um menor caminho entre dois vértices e mostra a quantidade de arestas.

O grafo não possui pesos. O menor caminho é o que passa pela menor quantidade de arestas.
